1. 系统概述

「长安智策」是西安市城市决策空间智能平台，通过 自然语言对话 + 空间地图可视化，为市民、游客、企业、商户、政府五类用户提供城市空间决策服务，覆盖 99 项功能。

一句话理解：像聊天一样说出你的需求（比如"哪里有空车位""办证要几步""下暴雨哪里会淹"），系统立刻把答案变成地图、流程、图表展示给你看。

图 1-1　PC 端首页：顶部 AI 输入框 + 示例需求，中间五大角色卡片（市民24 / 游客14 / 企业24 / 商户10 / 政府27），底部 99 项功能搜索

市民市民民生端（24 项）

停车、年检、物业维权、垃圾分类、快递、宠物办证、就学就医、养老、办事等

游客游客文旅端（14 项）

景区打卡、餐饮、线路、节庆活动、客流推演等

企业企业端（24 项）

选址、报建、政策补贴、用工、产业链、信用等全生命周期服务

商户小微商户端（10 项）

开店、证照、外摆、税费、夜市入驻等

政府政府治理端（27 项）

台账、评估、热力研判、内涝/客流仿真、空间治理等

2. 账号注册与登录

2.1 登录方式

方式适用用户说明
手机号 + 短信验证码全部用户最常用，首次登录自动注册
微信扫码登录市民/游客便捷，绑定手机号后使用
账号密码企业/政府/管理员由管理员统一分配
政务内网单点登录（SSO）政府治理端对接政务统一身份认证

2.2 实名认证

部分功能（如补贴申报、证照办理、企业选址）需 实名认证：个人用户需姓名 + 身份证号；企业用户需统一社会信用代码 + 法人信息。认证后解锁对应权限。

3. PC 端操作指南

3.1 进入首页

1
打开平台

浏览器访问平台网址，进入首页。首页顶部显示「数据更新时间」与「我的方案」数量。

2
了解五大端

首页展示 5 个角色卡片（市民/游客/企业/商户/政府），点击任意卡片展开该端全部功能清单。

3
搜索功能

首页搜索框可输入关键词（如「停车」「补贴」「内涝」），即时命中 99 项功能中的对应项。

图 3-1　首页的输入框（①）和五大角色卡（②），点击卡片或输入需求即可开始使用

3.2 输入需求并进入结果页

1
输入自然语言需求

在输入框用大白话描述需求，如「我想在曲江附近找空余车位」，点击「发送」。

2
系统识别意图

系统自动识别意图，显示匹配置信度（如 94%），并跳转到对应的 PC 端三栏结果页。

3
查看三栏结果

左侧为 AI 决策助手对话区，中间为核心展示区（地图/流程/图表），右侧为决策分析区（指标/洞察/动作）。

图 3-2　PC 三栏工作台：左（① AI 对话区，含意图识别与追问）、中（② 地图展示，停车场余位与违停高发段）、右（③ 决策分析，KPI + 洞察 + 动作按钮）
三栏说明：左 28% AI 对话区（含意图识别过程、推荐追问）；中 44% 核心展示区（按 6 类模式自动适配）；右 28% 决策分析区（关键指标 + 洞察 + 可执行动作 + 三按钮）。

4. App 端操作指南

App 端为 对话式 AI 界面，对齐移动端聊天应用体验。

1
进入 App 端

在 PC 工作台右上角点击「App 端视图」切换；或直接通过移动端小程序/H5 打开。

2
文字输入

底部输入框输入需求，点击发送按钮。

3
语音输入

点击麦克风按钮开始说话，实时转写文字，说完点「发送这句」或「取消」。

4
查看对话结果

AI 回复以气泡形式呈现，核心展示（地图/图表/流程）与决策分析直接渲染在对话卡片内，无需跳页。

图 4-1　App 端对话界面：顶部标题栏（① 含「切 PC 端」按钮）、中部 AI 回复气泡（② 内嵌决策分析卡片）、底部输入框（③ 含语音按钮）

6. 双端切换与方案管理

6.1 双端切换

  • PC → App：PC 工作台右上角点击「App 端视图」，切换到同一模块的 App 对话界面
  • App → PC：App 顶部点击「切 PC 端」，回到同一模块的 PC 三栏工作台
  • 关键：切换时当前模块不变，只是展示形态切换，方便在大屏和小屏间无缝衔接

6.2 方案管理

操作位置说明
调整条件重新生成右侧决策区底部修改条件后重新生成结果
保存方案右侧决策区底部保存当前结果快照到「我的方案」
导出 PDF顶部/右侧导出当前结果页为 PDF（含指标/洞察/流程/点位/明细）
我的方案首页顶部查看所有已保存的方案

7. 五类角色使用场景

7.1 市民：找停车位

首页输入「我想在曲江附近找空余车位，顺便看看有没有违停风险」
→ 系统识别为 C01 智慧停车 → 进入 PC 三栏
→ 中间地图显示停车场余位与违停高发段
→ 右侧给出「最优推荐/风险提示/错峰建议」+「导航/查看余位曲线/订阅预警」
→ 点击「导航至推荐停车场」跳转导航

7.2 游客：规划游览线路

输入「帮我规划一天的大雁塔周边游览」→ 识别为游客线路规划
→ 地图显示景区、打卡点、餐饮分布
→ 右侧给出线路建议与客流预测
→ 切换 App 端边走边看

7.3 企业：政策补贴申报

输入「我们企业符合哪些科技补贴」→ 识别为企业政策匹配（模式 C）
→ 中间显示匹配的补贴政策卡片（金额/条件/窗口/依据）
→ 点卡片看申报要点 → 一键定位办理点 → 保存方案导出 PDF

7.4 商户：开店证照办理

输入「我想在曲江开一家餐饮店，需要办什么证」→ 识别为商户开店（模式 B）
→ 中间显示办证流程步骤（环节/机构/时限/材料）
→ 点击步骤展开材料清单 → 预约办理

7.5 政府：内涝仿真推演

输入「如果下大暴雨哪些地方会淹」→ 识别为 G07 内涝仿真（模式 E）
→ 中间显示仿真推演（播放/暂停/时间轴）
→ 指标随帧刷新：积水点、管网负荷、影响人口
→ 导出 PDF 作为应急决策依据

8. 后台管理操作

8.1 管理员功能

模块功能说明
模块管理99 项功能上下线、排序、配置新增/编辑模块、设置别名关键词、话术
数据管理点位、政策、流程、指标维护录入/修正业务数据，审核后发布
用户管理账号、角色、权限分配五类角色权限控制、实名审核
意图训练样本管理、模型重训补充训练样本，提升识别精度
数据源管理外部数据源接入配置配置 API 密钥、同步频率、异常告警
审计日志操作留痕、安全审计满足等保合规要求

8.2 数据维护流程

1
录入/导入数据

管理员在后台录入或通过 Excel/API 导入业务数据（如新增停车场点位）。

2
数据校验

系统自动校验字段完整性、坐标范围、去重。

3
审核发布

提交审核，审核通过后数据上线，前端即时生效。

4
缓存刷新

发布后自动刷新 Redis 缓存，用户即时看到更新。

9. 常见问题与故障排查

问题可能原因处理方式
无法登录账号未激活/密码错误找回密码或联系管理员
意图识别不准表达过于模糊补充关键词重新描述；管理员补充训练样本
地图不显示点位地图服务异常/坐标错误刷新页面；联系运维检查地图 Key 与数据
停车场余位不更新数据源断连运维检查数据源 API 状态与同步任务
导出 PDF 失败浏览器打印组件异常更换浏览器或联系运维
语音转写无反应未授权麦克风权限在浏览器/系统设置开启麦克风权限
联系支持：如遇无法解决的问题，请联系系统管理员或拨打平台客服热线（上线后配置），并提供「操作时间 + 页面截图 + 报错信息」，便于快速定位。
