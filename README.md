# 长安智策｜西安城市决策空间智能平台 · 高保真可交互原型

按《功能与中间展示形式匹配表》开发的可运行原型，**99 项功能全部单独生成业务数据**，不使用统一模板换标题。

## 一、打开方式

直接双击 `index.html`（建议 Chrome / Edge）。纯静态、零依赖、无需构建与联网。

## 二、主流程（全程无功能菜单）

```
首页输入自然语言 → AI 识别意图（显示匹配置信度）→ 自动跳转对应子模块结果页
→ 中间区按模式展示结果 → 右侧决策区配套分析 → 调整条件重新生成 / 保存方案 / 导出 PDF → 返回首页发起新需求
```

- 首页：AI 输入框 + 10 条示例需求 + **99 项功能搜索框**（输入「停车」「补贴」「内涝」即时命中并可直跳）+ 5 大端入口（点击展开该功能域全部清单，可直跳）
- 左侧 28%：AI 对话区（含意图识别过程、匹配结果卡、推荐追问，点击即重新路由）
- 中间 44%：核心展示区，按 6 类模式自动适配
- 右侧 28%：决策分析区（关键指标 + 分析洞察 + 可执行动作 + 三按钮）
- 顶部：返回首页 / 匹配置信度 / App 端视图切换 / 导出 PDF

## 二、App 端（对话式 AI 界面）

在工作台顶部点「App 端视图」（或切 PC 端返回），进入 **对话式 AI 界面**，完全对齐移动端聊天应用体验：

- **底部输入 + 语音转写**：文本输入框 + 麦克风按钮（点击开始语音转写，实时显示转写文字，支持「发送这句 / 取消」；无语音权限时自动降级为演示转写）+ 发送按钮
- **上方对话流**：用户消息与 AI 回复呈气泡式对话；AI 回复直接把「核心展示」（含地图/图表/流程/政策/台账）和「决策分析」（关键指标 + 洞察 + 动作）渲染进对话卡片，无需跳页
- 顶部快捷追问条 + 对话内推荐追问，点击即重新路由
- 支持 iOS/Android 安全区（safe-area）、触摸滚动、小屏自适应

## 三、6 类中间展示模式（均含完整交互）

| 模式 | 适用 | 中间区构成 | 已实现交互 |
|---|---|---|---|
| A 空间地理类 | 点位查询、分布、路线 | 居中大地图 + 悬浮标题卡 + 结果卡片 | 滚轮缩放、拖拽平移、点位弹详情、图层开关、缩放复位、⤢ 放大弹层 |
| B 办事流程类 | 办事指引、证照办理 | 竖向步骤流程图（环节/机构/时限/材料/注意事项）+ 右侧点位缩略图 | 步骤展开材料、机构点位弹窗、小地图 ⤢ 放大 |
| C 政策清单类 | 政策匹配、补贴申报 | 政策卡片（金额/条件/窗口/依据）+ 配套点位地图 | 查看申报要点弹窗、一键地图定位办理点 |
| D 分析评估类 | 评估、体检、短板研判 | KPI + 柱状/条形/雷达/折线/环形/堆叠图 + 对比表 + 空间分布地图 | 图表动画、表头排序、搜索与类型筛选、点击行地图定位 |
| E 仿真推演类 | 内涝、客流、风险模拟 | 时序仿真地图 + 播放/暂停 + 时间轴 + 关键指标面板 | 自动播放推演、拖动时间轴、风险等级与指标随帧刷新 |
| F 台账统计类 | 台账盘点、资源普查 | 统计摘要 + 可筛选排序明细表 + 空间落图 | 搜索/类型过滤/排序/行点击地图定位 |

每个结果页底部均附「本页完整交互操作步骤说明」（按模式逐条生成）。所有地图均支持 ⤢ 一键放大为 460px 弹层视图（含缩放平移与点位详情）。

## 五、目录结构

```
index.html
assets/css/app.css            科技深蓝数字城市 UI（PC 多尺寸断点 + App 移动端 + 打印样式）
assets/js/core/geo.js         西安示意底图引擎（城墙/二环三环/水系/中轴 + 缩放平移 + 点位热力边界路线）
assets/js/core/charts.js      SVG 图表引擎（柱/条形/雷达/折线/环形/堆叠）
assets/js/core/app.js         意图识别、双端路由（PC 三栏 / App 对话）、6 类模式渲染、语音转写、保存/打印/追问
assets/js/data/*.js           99 项功能业务数据（按端拆分 8 个文件）
```

## 六、响应式适配

- **PC 端**：按屏幕宽度自适应 —— ≥1600px 超宽（首页四列清单）、1280~1600 大屏（默认）、1024~1280 中屏（三栏比例收紧）、768~1024 小屏笔记本（首页双列 + 三栏压缩）
- **手机 / 平板**：App 对话式界面为移动优先设计；小屏（≤480px）自动增大点击区域、加宽气泡、压缩地图高度，适配不同手机尺寸

## 七、说明

- 所有数据仅基于文档中约定的「西安公共政务开放数据 + 公开社会聚合数据 + 空间地理图层」口径构造，用于原型演示。
- 底图为抽象化示意底图（非真实瓦片地图），坐标按西安各片区相对位置锚定。
- App 端为对话式 AI 界面（底部输入 + 语音转写，上方对话框呈现核心展示与决策分析）；PC 端为三栏工作台。双端共用同一套渲染逻辑与业务数据。
- 导出 PDF：调用浏览器打印，在打印对话框选择「另存为 PDF」，已内置专用打印版式（隐藏界面框架，输出标题/指标/洞察/流程/政策/点位/明细/免责说明）。
